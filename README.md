# Simple Calculator in C

A command-line calculator built in C that performs basic arithmetic operations with input validation.

## Features
- Addition, subtraction, multiplication, division
- Modulus and power operations
- Handles divide-by-zero errors gracefully
- Loop-based menu — run multiple calculations without restarting

## How to run
1. Compile: `gcc calculator.c -o calculator`
2. Run: `./calculator`
3. Enter an operator and two numbers, or 'q' to quit

## Tech
Written in C using switch-case, loops, and basic error handling.
